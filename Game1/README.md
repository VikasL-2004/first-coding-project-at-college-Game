# Rock Paper Scissors Game

A responsive Rock Paper Scissors game built with HTML, CSS, and JavaScript. This was my first coding project during college.

## Features

- Play Rock, Paper, or Scissors against a random computer move
- Track player and computer scores
- Track consecutive winning rounds
- Reset the complete game from the interface
- Animated result banner and choice buttons
- Responsive layout for desktop and mobile screens
- Keyboard controls:
  - `R` for Rock
  - `P` for Paper
  - `S` for Scissors

## Technologies Used

- **HTML5** - Page structure and game interface
- **CSS3** - Styling, animations, gradients, and responsive design
- **JavaScript** - Game logic, scoring, keyboard controls, and DOM updates

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation or external dependencies are required.

## How to Play

1. Select Rock, Paper, or Scissors.
2. The computer randomly selects one of the three moves.
3. The result appears below the choices.
4. Scores and win streak update automatically.
5. Select **Reset Game** to clear the scores and start again.

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Selecting the same move produces a draw
